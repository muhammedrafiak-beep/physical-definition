How to run one exercise (open Flow, image mode, Nano Banana 2, 1:1)
1 · Base photo
  1. Open the Flow project, image mode, model Nano Banana 2, aspect 1:1.
  2. Add PD Model 2 as the character ingredient.
  3. Paste prompt 1 (START). Generate.
  4. One base serves every exercise with the same base tag — reuse it instead of generating a new one.

Image generation costs 0 credits.

2 · Masked edits
  1. Select tool → Box. Drag it from outside the canvas on all four sides, never leave a box edge inside the picture.
  2. Paste prompt 2 (END). Generate. Download.
  3. Back to the base, box again, paste prompt 3 (MID). Generate. Download.
  4. Then prompt 4 (ANATOMY) on each downloaded frame in turn.

Type with shift+Return between lines. One change per generation — pose, then anatomy, never both.

3 · Build the loop
  1. Put the downloads in one folder.
  2. Run the command shown under the prompts, in cmd.
  3. Open the -frames.png contact sheet and check the pose and the muscle.

Residual under 12 = ships. 40 or more = Flow redrew the scene, regenerate that frame.

Rules that were paid for
  1. Numbered list, one instruction per line. Never a paragraph.
  2. An angle in degrees is ignored — anchor it to something visible instead.
  3. Flow draws him facing right, so side views get mirrored in the script.
  4. The loaded muscle must never be wrong. Check the contact sheet before shipping.
